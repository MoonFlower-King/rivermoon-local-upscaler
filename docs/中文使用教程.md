# RiverMoon 本地超分使用教程

## 1. 这个工具是什么

RiverMoon 本地超分是一个 Windows 桌面应用，用来在本机把图片高清放大。当前版本只保留网站同款 AI：

```text
ComfyUI + PyTorch/CUDA + 4x-UltraSharp.pth
```

不需要打开网页，不需要 NewAPI Key，也不会把图片上传服务器。

## 2. 打开软件

进入：

```text
D:\rivermoon-local-upscaler\release\win-unpacked\
```

双击：

```text
RiverMoon 本地超分.exe
```

发给其他电脑时必须复制整个 `win-unpacked` 文件夹，不能只复制 exe。

## 3. 基本使用

1. 打开软件后会直接进入工作区。
2. 把图片或文件夹拖到左侧工作区，也可以点 `添加图片` 或 `添加文件夹`。
3. 右侧确认输出格式、最大长边、输出目录。
4. 点击 `开始处理 N 个任务`。
5. 完成后点击 `对比` 查看前后效果，或点 `打开位置` 查看输出文件。

默认输出目录是原图同级的：

```text
upscaled
```

## 4. 右侧检测卡

右侧有一个小的运行状态卡片。它只负责检查：

- 内置 ComfyUI Runtime 是否存在。
- CUDA 是否可用。
- `4x-UltraSharp.pth` 是否存在。

软件不会再用一个大页面挡住工作区。需要确认环境时，点击卡片里的 `检测`。

## 5. 参数说明

### 输出格式

- PNG：默认推荐，质量高，文件较大。
- JPEG：文件较小。
- WebP：文件更小，但部分老软件不支持。

### 最大长边

默认是 `4096`。

- `4096`：更接近旧网站 AI 输出尺寸。
- `0`：真实 4x 输出，图会更大，也会更慢。
- 其他数字：输出图最长边不超过该值，并保持比例。

### 输出目录

不设置时，输出到原图同级目录的 `upscaled` 文件夹。也可以手动选择一个固定输出目录。

## 6. 任务记录

任务记录会一直保留在本机：

```text
release\win-unpacked\user-data\jobs.json
```

关闭软件再打开，历史任务仍然在，最新生成的任务会显示在最前面。

任务卡片会显示计时：

- 运行中显示 `已用`。
- 结束后显示 `耗时`。
- 关闭重开后，历史任务仍会保留耗时。

如果关闭软件时有任务还在运行，下次打开会标记为：

```text
上次关闭软件时已停止
```

## 7. 进度说明

当前进度来自 ComfyUI 真实事件：

- websocket `progress_state`
- websocket `progress`
- `/history/{prompt_id}` 完成状态

如果 websocket 临时不可用，软件会用 history 轮询判断是否完成，但不会按时间伪造百分比。所以有时进度会停在某个阶段，这是正常的，表示正在等 ComfyUI 返回真实状态。

## 8. 前后对比

任务完成后点击 `对比`：

- 拖动滑块看处理前后。
- 鼠标滚轮或 `+ / -` 按钮缩放。
- 放大后可以拖动画面。
- `重置` 回到 100%。

## 9. 常见问题

### 提示缺少网站同款 Runtime

确认你复制的是完整目录，并且存在：

```text
resources\comfyui-runtime\python_embeded\python.exe
resources\comfyui-runtime\main.py
resources\comfyui-runtime\models\upscale_models\4x-UltraSharp.pth
```

### CUDA 检测失败

当前版本需要 NVIDIA 显卡和可用驱动。处理方式：

1. 安装或更新 NVIDIA 官方驱动。
2. 关闭占用显存的软件。
3. 重新点击右侧卡片的 `检测`。

### 为什么本地比网站慢

本地速度取决于你的显卡、图片尺寸、首次加载模型耗时和是否已经启动 ComfyUI。网站可能是更强的服务器 GPU。本地当前链路已经是网站同款 AI，不是 Pro/SUPIR。

默认 `4096` 会更接近网站输出；填 `0` 真实 4x 会明显变慢。

### 为什么没有 Pro / SUPIR

这两个链路对配置要求高，速度慢，并且更容易造成用户误以为是网站同款 AI。当前产品只保留网站同款 AI，后续除非重新确认产品方向，不建议接回。

## 10. 发给客户前注意

- `4x-UltraSharp.pth` 有非商业授权风险，商业分发前必须确认授权或替换模型。
- 当前没有 CPU、DirectML、AMD/Intel fallback。
- 未签名 exe 可能被 Windows 提示未知发布者。
