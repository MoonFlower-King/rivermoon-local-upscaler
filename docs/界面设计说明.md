# 界面设计说明

当前桌面端 UI 按“苹果原生轻量工具软件”方向实现。

## 视觉关键词

- macOS 浅色窗口。
- 极简工具型布局。
- 大量留白。
- 低饱和配色。
- 磨砂玻璃面板。
- 柔和微弱阴影。
- 圆角输入框。
- 原生感按钮。
- 清晰功能分区。
- 干净商务风。

## 页面结构

打开软件后直接进入工作区：

1. 顶部标题区：产品名、短说明、关于入口、刷新状态。
2. 左侧工作区：拖拽上传、待处理图片、任务记录、前后对比入口。
3. 右侧状态卡：网站同款 AI 可用性、CUDA 检测按钮、队列统计。
4. 右侧设置区：固定网站同款 AI、输出格式、最大长边、输出目录。

兼容性检查不能再做成首屏大页面。

## 样式规则

- 背景使用浅灰到近白的柔和渐变，不用装饰性光斑。
- 面板使用半透明白色和 `backdrop-filter: blur(...)`。
- 圆角控制在 10px 到 20px 之间。
- 主按钮使用低饱和蓝色。
- 进度条使用蓝绿柔和渐变。
- 文字层级保持紧凑：标题清晰，说明文字灰色弱化。

## 已落地

- 简洁线性品牌图标。
- 小卡片状态检测。
- 网站同款 AI 固定链路卡片。
- 任务记录持久化并最新在前。
- 前后对比弹窗支持缩放和拖动。
- 关于页和诊断日志入口。
