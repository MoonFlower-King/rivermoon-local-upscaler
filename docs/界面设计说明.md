# 界面设计说明

当前桌面端 UI 按“苹果原生轻量工具软件”方向实现：浅/深双主题跟随系统（`prefers-color-scheme`），叠加 Win11 系统级亚克力毛玻璃（acrylic vibrancy）。

## 视觉关键词

- macOS 风格窗口，浅/深双主题跟随系统。
- 系统级亚克力毛玻璃（Win11 acrylic vibrancy）。
- 极简工具型布局。
- 大量留白。
- 低饱和配色。
- 磨砂玻璃面板。
- 柔和微弱阴影。
- 圆角输入框。
- 原生感按钮。
- 清晰功能分区。
- 干净商务风。

## 页面结构

打开软件后直接进入工作区：

1. 顶部标题区：产品名、短说明、关于入口、刷新状态。
2. 左侧工作区：拖拽上传、待处理图片、任务记录、前后对比入口。
3. 右侧状态卡：网站同款 AI 可用性、CUDA 检测按钮、队列统计。
4. 右侧设置区：固定网站同款 AI、输出格式、最大长边、输出目录。

兼容性检查不能再做成首屏大页面。

## 样式规则

- 窗口底层由主进程设置 Win11 22H2+ 的 `backgroundMaterial: "acrylic"`；渲染层背景用半透明 `--window-tint` 让系统毛玻璃透出来，不支持 acrylic 的系统自动回退纯色底（浅色 `#f0f2f5` / 深色 `#1d1d20`，跟随 `nativeTheme`）。不用装饰性光斑。
- 设计 token 分浅/深两套：`:root` 为浅色，`@media (prefers-color-scheme: dark)` 覆盖为深色；颜色一律走 CSS 变量，不写死。
- 面板使用半透明材质色（`--material-panel`、`--surface-card` 等 token）和 `backdrop-filter: blur(...)`。
- 圆角控制在 10px 到 20px 之间。
- 主按钮使用系统蓝（浅色 `#007aff` / 深色 `#0a84ff`）。
- 进度条使用蓝绿柔和渐变。
- 文字层级保持紧凑：标题清晰，说明文字灰色弱化。

## 已落地

- 浅/深双主题 + Win11 acrylic vibrancy，跟随系统实时切换。
- 简洁线性品牌图标。
- 小卡片状态检测。
- 网站同款 AI 固定链路卡片。
- 任务记录持久化并最新在前。
- 前后对比弹窗支持缩放和拖动。
- 关于页和诊断日志入口。
