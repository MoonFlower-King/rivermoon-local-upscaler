# 界面设计说明

RiverMoon AI 创作台采用安静、紧凑的桌面工具布局，支持浅色/深色主题与 Win11 acrylic 背景。

## 导航结构

```text
创作
  AI 生图
  AI 视频
  GPT 对话

工具
  图片超分
  资产库

底部
  账户余额
  设置
```

新用户默认进入 AI 生图；已使用用户恢复上次模块。

## 生图工作区

```text
image-workbench
  image-settings-rail      模型、尺寸、质量、参考图、分镜模板
  image-creation-stage     提示词、提交状态、未来无限画布入口
```

小窗口下两列自动变为纵向布局，不能产生水平滚动或文本遮挡。未来无限画布只替换 `image-creation-stage`，合同和任务逻辑继续由现有模块管理。

## 其它工作区

- AI 视频：参数、模式、参考图和提交状态集中在一个工作区，任务记录独立显示。
- GPT 对话：左侧本机历史，右侧对话、模型、推理强度和附件输入。
- 图片超分：拖放和任务记录为主，固定链路设置位于右侧。
- 资产库：统一展示图片、视频和超分结果。
- 设置：账户、GitHub 更新和诊断入口。

## 视觉规则

- 使用 CSS token 支持浅色/深色模式，不在组件中硬编码主题色。
- 工具按钮优先使用 Lucide 图标和 tooltip。
- 卡片圆角不超过当前设计系统要求，避免卡片嵌套。
- 状态颜色只表达就绪、警告和错误，不作装饰。
- 固定尺寸控件使用稳定网格，动态文本不得推动布局跳动。
- 1440x900 和 980x680 是发布前必测视口。
