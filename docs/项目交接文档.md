# RiverMoon 本地超分项目交接文档

## 交接对象

交给本地 Claude Desktop 继续处理。

## 当前产品定位

这是一个独立 Windows 本地图片超分桌面工具。当前最新版只保留网站同款 AI：

```text
ComfyUI + PyTorch/CUDA + 4x-UltraSharp.pth
```

不连接服务器，不使用 NewAPI Key，不上传图片。

## 工作目录

```text
D:\rivermoon-local-upscaler
```

请勿改回历史的旧 Web 项目目录（仅用于追溯网站 AI 链路，不参与当前桌面版开发）。

## 最新产物

```text
D:\rivermoon-local-upscaler\release\win-unpacked\RiverMoon 本地超分.exe
```

交付时复制整个目录：

```text
D:\rivermoon-local-upscaler\release\win-unpacked\
```

不能只复制 exe。

## 本轮已完成的关键改动

- 关闭重开后任务记录仍保留。
- 任务列表按 `createdAt` 倒序，最新任务显示在最前。
- 每个任务新增 `durationMs`，运行中 UI 显示“已用”，结束后显示“耗时”。
- 只保留 `网站同款 AI`，新任务强制使用 `ComfyUI + 4x-UltraSharp.pth`。
- UI 打开后直接进入工作区。
- 兼容性/资源检查改为右侧小卡片。
- 启动时不自动跑完整 CUDA 自检，用户点 `检测` 才跑。
- ComfyUI 进度改成真实同步：优先 websocket `progress_state`，兼容 `progress`，用 history 判断完成。
- websocket 不可用时只轮询 history，不再按时间伪造进度。
- 对比弹窗支持缩放和拖动画面。
- 打包过滤掉 DiffBIR/SUPIR 和其他 upscale 模型，只保留 `4x-UltraSharp.pth`。

## 当前功能

- 中文界面。
- macOS 浅色工具软件风格。
- 单张图片、文件夹批量处理。
- PNG/JPEG/WebP 输入输出。
- 输出格式、最大长边、输出目录设置。
- 任务队列、取消、失败提示、打开输出位置。
- 任务记录持久化。
- 成功任务前后对比预览。
- 关于页、日志目录、诊断日志导出。

## 核心链路

```text
LoadImage
-> UpscaleModelLoader(4x-UltraSharp.pth)
-> ImageUpscaleWithModel
-> ImageScale(Lanczos)
-> SaveImage
```

默认最大长边：

```text
4096
```

用户填 `0` 时真实 4x。

## 主要代码位置

```text
src/main/main.ts             Electron 主进程、IPC、资源状态、诊断导出
src/main/job-queue.ts        队列执行、任务排序、任务状态推送
src/main/jobs-store.ts       jobs.json 持久化，兼容旧任务并补算耗时
src/main/comfy-engine.ts     ComfyUI 启动、prompt、真实进度、输出复制/转码
src/main/hardware-probe.ts   ComfyUI Runtime / CUDA 检测
src/main/settings.ts         强制规整到网站同款 AI
src/main/settings-store.ts   settings.json 持久化
src/renderer/main.tsx        UI
src/renderer/styles.css      样式
```

旧轻量链路遗留文件：

```text
src/main/upscaler-engine.ts
src/main/engine-errors.ts
resources/engines
resources/models
```

当前产品不使用它们。除非用户明确改变方向，不要重新接回。

## 运行和打包

```bash
npm install
npm run dev:electron
npm run build
npm run dist:dir
```

本机可能有 `ELECTRON_RUN_AS_NODE=1`，开发运行请用 `npm run dev:electron`。

## 验收要求

每次改动至少执行：

```bash
npm run build
```

发版前执行：

```bash
npm run dist:dir
```

然后启动：

```text
release\win-unpacked\RiverMoon 本地超分.exe
```

检查：

- 首屏是否直接显示工作区。
- 右侧检测卡是否存在。
- 只看到网站同款 AI。
- 拖图后能生成输出。
- 任务记录最新在前。
- 任务完成后显示耗时，运行中显示已用时间。
- 关闭重开后任务记录仍在。
- 对比弹窗能缩放。

## 已知限制

- 需要 NVIDIA/CUDA。
- 没有 CPU、DirectML、AMD/Intel fallback。
- `4x-UltraSharp.pth` 有非商业授权风险。
- 未签名 exe 可能触发 Windows 未知发布者提示。
